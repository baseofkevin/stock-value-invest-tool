选股 stock_kline_screen

./run.py select

定位：谁刚刚启动（量价）

  • 粗筛：K=n+1=5 个交易日里任一天涨幅 ∈ [0.5%, 20.5%] → 池 ≈ 4300 只
  • 排除：名称含 ST；次新（上市<3 年）只对幸存者惰性查
  • 启动日 d*：连续收盘>MA20 回扫 ≤20 根，且前一日未站上 MA20（真上穿）；需 ≥71 根
  • ⑦ age ≤4 │ ② 放量 ≥1.5× │ ③ d* 涨幅 ∈[0.5,20.5]%
  • ④ MA20 ≥ MA60×0.95 且 MA20 > 3 日前 ×0.99
  • 换手分位只排序（--turn-pct 0），不删票
  • 入选后标注：毛利率改善、一级行业、市值、分位星级（只展示，不裁决）

周期弹性 stock_cycle_elastic

./run.py cycle

只给标签，不评分不排序

  • ① 周期股：20 季毛利率 σ ≥5pp；或 CV ≥20% 且中位 ≥5% 且 σ ≥2pp
  • ② 弹性：8 季 DOL（环比利润增速 ÷ 营收增速）中位 ≥2.0 → 强
  • 　 不稳定：营收同比中位 <3%，或利润跨零 >1/3（取代强 / 弱）
  • ③ 位置：产能周转率 40 季分位 <40% 低位、>60% 高位；40~60 不给标签
  • 金融股位置标「不适用」；方向标「扩产中 / 产能在退」
  • 窗口：取 44 季（40 季位置 + 4 季算同比）；<20 季标「历史不足」仍出报告
  • 「弱」与「不稳定」严格分开：前者是知道且不强，后者只是算不出来

质量初筛 stock_quality_screen

./run.py quality

Q + V + 14 项风险 → 一句结论

  • Q100 = 资本回报 30 + 现金 25 + 资产负债表 20 + 成长 15 + 会计 10
  • V100 = 目标价空间 40% + 预测PE相对 20% + 净利增速 40%（无覆盖不算 V）
  • 14 项风险（真伪 / 趋势 / 质量 / 安全）→ 命中 / 提示 / 已知
  • 4 条致命直接回避：净资产为负、利息保障<1、商誉>50%、3 年经营现金流为负且净负债/EBIT>4
  • 结论 = Q×V 矩阵 9 种；Q<45 一律回避；一致性闸门：命中 ≥2 项，买入类降为回避
  • 数据前置不满足（机构覆盖不足 / 关键检查缺失）→ 观察，等待数据完整

选股：七条规则与逐股去向

stock_kline_screen/rules.py · params.py

  • ⑦ 新鲜度：age = S − d* ≤ N（每周 N=4）
  • ② 放量：vcross = 量(d*) ÷ 前 5 日均量 ≥ 1.5
  • ③ 日频：d* 在覆盖窗口内，且当日涨幅 ∈ [0.5, 20.5]%
  • ④ 均线：MA20(d*) ≥ MA60×0.95；MA20(d*) > MA20(d*−3)×0.99
  • ⑤ 风控：d* 与 S 各查一次——非 ST、非次新（<3 年）
  • ⑥ 未破坏：d*+1..S 收盘均在 MA20 上方（定义性，恒不触发）
  • 去向只有三种：FS（定位失败）/ JD（裁决失败）/ TN（换手硬过滤）
  • 收尾断言：粗筛池 = 入选 + Σ剔除，且两边无交集
  • 换手：20 日均额 ÷ S 日流通市值；分位 <20/40/60 给 ★★★ / ★★ / ★
  • 门槛：MIN_HISTORY=70（含当日 ≥71 根），不足直接判 FS

周期：三判据与三档

stock_cycle_elastic/config.py · decide.py

① 是不是周期股（两条通道 OR）

  • 绝对：20 季单季毛利率 σ ≥ 5.0pp
  • 相对：CV = σ/|中位| ≥ 20%，且中位 ≥5%、σ ≥2.0pp

② 弹性（8 季环比 DOL 中位数）

  • ≥2.0 强 / <2.0 弱 / 营收同比中位 <3% 或跨零 >1/3 → 不稳定

③ 周期位置（产能周转率 40 季分位）

  • <40% 低位 / >60% 高位 / 中间不给标签；金融股「不适用」

数据保护（不是判定阈值）

  • 单季营收增速 <0.5% 则该季比值跳过；比值 >50 剔除；样本 <4 置空

判据来源：东北证券 5pp / 招商 30% 出清口径放宽到 40%

页面上的「· 订单回升」是另一回事

  • 合同负债同比 ≥+20% / ≤−10%，且占年化营收 ≥2% 才认；只加限定语，不改分位与标签

顶部：四因子 + 四条旁证

stock_judge_top（indicators / judgement / extras）

  • 动量：pos250 定位置（−5% 内高位 / −20% 内中位 / 其余低位），ret20 定速度（过热 / 偏热 / 走平 / 偏弱）
  • 换手：av20 与 ratio，分母用当期流通市值；缺市值改成交额分位
  • 业绩：季报营收与利润同比，看「撑不撑得住」
  • 量价：高位用 pos250——下跌中继不再被误判成高位盘整
  • 旁证：估值十年分位、机构目标价与空间、应收 / 存货 / 现金流反证、周期状态
  • 纪律：四因子不合并、不打总分；周期状态只进旁证表，不另出卡片
  • 输出：四因子状态词 + headline，一句话说清「为什么不是顶部」
  • 只有「高位 + 热」才叫「高位加速」，反弹不当顶部信号

A股大势：三路口径与阈值

stock_market_trend/rules.py

趋势（沪深300 周线）

  • 连续 2 周收盘 < MA20 → 偏弱；MA20 < MA60 且 MA60 低于 4 周前 → 空头条件
  • 两条同时成立 → 空头确认；否则 MA20 > MA60 且价 > MA20 → 偏强，其余中性

赔率（ERP 分位）

  • ERP = 100/PE(TTM) − 10Y 国债，近 2400 个交易日：≥95 极值 / ≥80 便宜 / ≤20 偏贵

情绪（破净 + 周换手五档）

  • 全A破净率近 2400 日分位：≥90 恐慌 / ≥70 偏冷
  • 地量 ≤1% / 缩量 <0.9M / 平稳 0.9~1.1M / 放量 ≥1.1M / 天量 ≥1.5M
  • M = 近 52 周换手中位；除 1% 这个地板，另三条线逐周现算、跟着水位漂
  • 周中「本周至今」那根摘掉不判，按上一完整周判（档位晚一周，不会高估）

三路不合成、不加权、不排序；只作背景板，不参与四个工具的任何判断
