价值投资量化工具，非常简单的、自己完全理解且正在使用的工具。

1.做股票一定要有稳定的现金流，股票是要等风来的，这个风可能几个月也可能几年才来，要等得起。

2.千万不要加杠杆，因为不知道未来短期市场是涨还是跌，只要没有杠杆就不会有资金永久损失的风险，只要在场，就有翻身的可能。

3.关键在于选择标的和买入时的估值，后续就是坚持持股，不要止损，也不要做短线，这些短期的操作都是不可控，等涨到目标价位直接卖出，再选择下个目标。

4.股票是买预期，卖现实。预期，就是企业的未来要有业绩和叙事的共振，这样的股票才会有大概率上涨，没有未来叙事（比如红利股）的股票不要买。卖现实，就是业绩兑现了的时候。
