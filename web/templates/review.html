优先研究过了硬门槛，且赔率分 ≥ {{ review.cut }}（满分 {{ review.score_max }}，见下表）。
档内排序按赔率分从高到低；同分看盈利弹性（强的靠前），然后 Q，最后按代码。
市值小<50 亿 +3；<100 亿 +2；<200 亿 +1；更大或没有市值 0。 来自选股工具的 market_cap_yi。
估值低位PE / PB / PS 三项历史分位的均值：≤25% +3；≤50% +2；≤70% +1。 分位来自质量工具的 v.historical.metrics，151/151 都有值。
周期低位周期股、且产能周转率分位 < 40%：+2。非周期股不加不减 （这个指标对它没意义）。
盈利弹性强 +2；「不稳定」+1（营收走平/利润跨零，是算不出来， 不是差）；弱 0。
垄断性shared.db 的 annotation 表里有标注：+2。 「无标注」和"没查过"都是 0 分——不扣分，因为没核实不等于没有。
质量Q ≥ 80 +2；≥ 65 +1。给质量留分是刻意的：否则好公司会因为 市值大而沉底。
目标价空间机构目标价 ≥ +20%：+1。只覆盖 79/151（48 只没目标价、 24 只是"现价缺失"的空壳），所以只给 1 分、不做门槛。
扣分趋势走弱（毛利率或合同负债判坏）−2；V 分 < 55 −1。

为什么扣分而不是否决：毛利率一个季度走弱不等于公司坏了，机构没有覆盖更不等于 公司不好（V 缺的 63 只里 60 只市值 <200 亿，把它当门槛等于系统性排除小市值）。 这些是"研究时留意"，不是"不许买"。

弹性加分对周期股和非周期股都给，但含义不同：DOL 在周期股身上是 「周期反转时利润弹得快」，在非周期股身上只是固定成本占比高（经营杠杆）。 所以非周期股的强弹性在「为什么值得看」里会标一个「·存疑」——工具对这种组合 自己也标的是「①否②强·存疑」。分数照给，提示照标。

没跑周期弹性的批次，这两项都无从判断（`+0`），页面会提示「缺周期数据」—— 补跑一次 ./run.py cycle --from-select <基准日> 就有。

阈值都在 web/review.py 顶部（BUY_CUT / MCAP_STEPS / PCT_STEPS / Q_STEPS / TREND_PENALTY），改一个数刷新页面就生效——没有藏在别处的魔法权重。 实测切点：14 只（5 分）／19 只（4 分）／8 只（6 分）。
利润弹性的阈值不在这里：2× 是 stock_cycle_elastic 的 ELASTIC_RATIO_MIN，这一页只读它给出的「强/弱/不稳定」，不另定一条线。
